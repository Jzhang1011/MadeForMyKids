Practice with a Partner 👥

WIDI is a team event: one person writes, another builds, and the builder never sees the original. The screen can't teach that — a partner can.

How a practice round works

  1. Set the target. The writer picks a challenge below (or builds a physical model from rods and connectors). Only the writer looks at it.
  2. Writer observes and writes. Numbered instructions, no touching the model while writing if your practice rules say so. Builder looks away.
  3. Builder rebuilds. Using only the written instructions and the allowed pieces. The writer watches silently — no hints, no pointing.
  4. Compare. Put both structures side by side. Work through the checklist below.
  5. Rewrite. Find the sentence responsible for each mismatch and rewrite it. That's where the learning lives.

Fair play: the writer never sees the builder's reconstruction in progress, and the builder never sees the target until the comparison.
