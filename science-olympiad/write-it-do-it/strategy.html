Improve Your Strategy 📈

Good builders aren't faster hands — they're better systems. Four habits separate strong teams from stuck ones.

The 4 habits

  1. Organize before you write. Number every step. Group related steps into sections. Build the base first, then connections, then details.
  2. Manage your practice time. In practice, give the writer a fixed window and the builder a fixed window — then compare. Rushing the writing is where most points are lost.
  3. Review for omissions. Before calling instructions done: does every piece in the inventory appear? Does every rod end plug into a named opening?
  4. Decide which details matter. Not every detail scores. Piece identity, connections, and positions decide the build; decorative description doesn't. Spend words where points live.

These are practice habits drawn from team workshops — not official rules. The current 2027 rules manual is the only authority on event format and timing.

Deep dive: organizing long instructions
  • Write the overview first: one or two sentences describing the whole structure.
  • Define the reference system once at the top — then never redefine it mid-instructions.
  • Build independent subassemblies separately, then describe joining them.
  • Make reversible changes before irreversible ones: place before you fasten, position before you commit.
  • End with an inventory check: count pieces in the instructions against the parts list.
Deep dive: time management in practice
  • Agree on direction words with your partner before the timer starts — north/south/east/west or a clock face beats "left" and "right."
  • Agree on a distance unit (a knuckle, a finger width) so estimates are consistent.
  • The writer's scarcest resource is clarity, not speed. A calm, complete description beats a rushed, hole-filled one.
  • Save decorative details for last — if time runs short, the structure must already be buildable.
