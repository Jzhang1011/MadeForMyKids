Find and Fix Ambiguity 🔎

An ambiguous instruction isn't wrong — it's worse. Two builders read it two ways and build two different structures.

The test: could two builders disagree?

Read each sentence below. If two reasonable builders could build different things from it, it's ambiguous. Rewrite it, then compare with the model answer.

Ambiguity patterns to memorize
  • Piece identity: "the red piece" when several red pieces exist. Fix: name color + length + which one.
  • Direction: "on the left" with no reference. Fix: "on the left of what."
  • Orientation: "put the connector down" with no facing. Fix: name which way every opening faces.
  • Connection points: "attach A to B" with no ends or openings. Fix: "the rod's left end into the connector's right-facing opening."
  • Relative position: "near the middle." Fix: anchor to a reference edge + a distance.
  • Missing steps: jumping from step 2 to step 5. Fix: number every step; check the inventory at the end.
