Observe Like an Engineer 🔍

Every good instruction starts with careful looking. Inspect every model in the same order, so nothing gets missed.

The 7-step inspection

Run through these steps in order before you write a word. Writers who skip steps write instructions with holes in them.

  1. Inventory: count each type of piece separately — rods by color and length, connectors by kind.
  2. Orientation: fix your viewpoint. Name the base, front, back, left, and right — and say which edge faces you.
  3. Structure: find the major sections and any independent subassemblies you could build separately.
  4. Connections: for every rod, record which pieces it connects, where they connect, and how (which opening, which end).
  5. Position: describe relative placement — direction and distance from a fixed reference point.
  6. Details: capture colors, sizes, angles, and anything else that scores points.
  7. Review: check for missing pieces and ambiguous descriptions before you call it done.

Not every object fits the same coordinate system. Pick a reference system that makes this model easy to describe — a grid, a clock face, "front-left corner" — and define it clearly at the top of your instructions.
