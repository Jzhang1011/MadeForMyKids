Adaptive tiered test

One test that moves between three tiers — Beginner (Level 1 questions), Early intermediate (Level 2) and Intermediate (Level 3) — based on how you answer. This is our own simple practice design.

Tier rules

  • Reading & Listening: start at Beginner. 3 correct in a row → up one tier (max Intermediate). 2 wrong in a row → down one tier (never below Beginner). The streak resets whenever the tier changes. 30 scored questions, never repeated, plus an unscored practice question first.
  • Writing & Speaking: start at the tier you ended Listening on (or Reading if Listening isn’t done; otherwise Beginner). After each prompt, meeting that tier’s target moves you up one tier; not yet moves you down one.
  • Suggested order: Reading → Listening → Writing → Speaking.
