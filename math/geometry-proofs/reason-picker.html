How to decide, in order

  1. Does it cross = / ≅? If the statement turns an = into a ≅ (or the reverse), it's the Definition of Congruence.
  2. Same algebra on both sides? Adding, subtracting, multiplying, or dividing the same thing on both sides → a property of equality.
  3. Names a picture-word? Vertical, linear pair, midpoint, bisector, perpendicular, "between" → find that definition, theorem, or postulate.
  4. Same thing twice, flipped, or chained? A = A → reflexive. A = B turned into B = A → symmetric. A → B and B → C giving A → C → transitive. Match the symbol (= or ≅).
